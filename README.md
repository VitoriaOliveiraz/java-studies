3. [⚡ **03 · Estrutura Sequencial, Entrada/Saída, Casting e Prática**](anotacoes/03-estrutura-sequencial.md)
   - Tabela de tipos primitivos e limites de memória.

   - Conversão de tipos (*casting*) e o operador resto `%`.
   - Entrada de dados com `Scanner` e o bug clássico da quebra de linha pendente no buffer.
   - Lista de exercícios resolvidos (1001 a 1014) e desafios pendentes mapeados.

## ▶️ Como Rodar

1. Certifique-se de ter o **JDK 17+** instalado (gerenciado via **SDKMAN** ou instalador oficial).
2. Abra a pasta `java-studies` diretamente no **IntelliJ IDEA**.
3. Navegue até o exercício desejado dentro de `udemy/src/estrutura_sequencial/` ou `dio-bootcamp-itau/src/` e clique no botão verde de **Run** (ou atalho `Shift + F10`).
